01 What it found

Nobody told it where to look.

Every result here comes out of the public SPHEREx images by documented, deterministic arithmetic. Each one was checked against an independent source.

An interstellar comet

It caught 3I/ATLAS.

The blind search picks up the comet crossing a field at 99″ per hour, in fifteen exposures of 7–8 August 2025. It links what moved between exposures; nothing tells it which objects are known.

How much the search finds

Motion, measured

10.33″ per year.

For any object the service measures a position on the native detector pixels of every exposure, then fits its motion. Barnard's Star: 86 positions, thirteen months.

Checked against Gaia DR3: 10.36″ per year, and a position 0.1″ from its prediction.

02 A tour

Six things to do with the whole sky.

Every picture is a real view of the live site. Nothing to install, no account.

  1. 01 · Pick a spot

    Start from a map of the whole sky.

    Drag it, zoom into the 2MASS infrared photograph, click anywhere. Or type coordinates or a name. Simple mode for a first look, Advanced for the full instrument.

    Open the sky map

  2. 02 · Blink the sky

    Play every image of that patch in time order.

    Frames per day, per six-month sky pass or per exposure, in any of the six detector bands. Subtract the median and the static stars vanish; what is left moved or changed.

    Blink Barnard's Star

  3. 03 · Read a spectrum

    102 colours of one object, read for you.

    Every exposure sees the target at another wavelength. For the brown dwarf Epsilon Indi B the viewer names the water and methane bands by fixed, cited rules, and says how sure it is.

    Read Epsilon Indi B

  4. 04 · Watch it change

    Brightness at every visit, band by band.

    The Mira variable R Draconis faded by a factor of two between June 2025 and June 2026. One line says whether an object changed, and in which bands.

    Watch R Draconis

  5. 05 · See how far

    Distance, redshift and look-back time.

    Published distances of stars and redshifts of galaxies, and a redshift measured from the lines of the SPHEREx spectrum itself. When a catalogue disagrees, it says so.

    Open a quasar

  6. 06 · Follow the discoveries

    A public log of everything that moved.

    Every moving object found as people open wide fields is kept, named from the catalogues of known bodies, and can be voted real or false. So far, all of them are known: the result a search that works should give.

    Open the log in Advanced mode

03 How it works

It reads under 3 % of each file. Nothing is downloaded in advance.

A SPHEREx file is about 65 MB. The server asks the archive only for the bytes of your cutout, so a new 8 arcmin view of about 350 exposures is on screen in about ten seconds.

1.3–1.9 MB read per exposure65 MB the file
  1. 01

    You pick a spot

    A click on the map, coordinates or a name.

  2. 02

    Find the exposures

    The archive lists every SPHEREx image that covers it.

  3. 03

    Read only the bytes

    Four range requests per file from the public AWS mirror.

  4. 04

    Clean and align

    Mask bad pixels, subtract the sky, resample north-up.

  5. 05

    Keep it

    Cached on disk: under one second the next time.

  6. 06

    Play it

    Epochs, colour and the movie, drawn in your browser.

No AI inside

No machine-learning model runs in the product. Every image is NASA SPHEREx data processed by documented arithmetic, and every reading cites its rule.

The same pixels

A cutout read by range requests is identical, pixel for pixel, to one cut from the full download. The speed costs nothing in accuracy.

No framework

The viewer is plain HTML, CSS and JavaScript with no build step. The server is one FastAPI process with its own workers.

04 API

One URL, one picture.

Every view is an address, and every picture and measurement has an endpoint. Link it, embed it or fetch it from your own code. Reading is open to any page: no key, no account.
